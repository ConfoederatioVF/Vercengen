    Geospatiale

    The namespace for all UF/Geospatiale utility functions, typically for static methods.

    Regular operations use Turf.performant, which is a custom fork of Turf.js. It has the same syntax, but features 60-120x the performance (average over union, difference, intersect).

    See GeoJSON converters (i.e. convertMaptalksToTurf, convertTurfToMaptalks) for information on its usage. For frontend GIS editing, please review Naissance HGIS.
